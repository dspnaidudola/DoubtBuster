# User Guide

1. Start the app with `streamlit run app.py`.
2. Select the subject, topic, skill level, and learning mode in the sidebar.
3. Enter your question or upload a supported text-based file.
4. Optionally add your own attempt.
5. Click **Help me understand**.
6. Read the explanation, check assumptions, and try the follow-up question.
7. Use the Practice page to generate a similar question.

AI output can be incorrect. Independently verify important calculations and code results.
